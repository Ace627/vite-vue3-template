本项目是基于 Vite 8（Rolldown 打包）+ Vue 3 + TypeScript 的前端工程化样板，定位纯前端、不接后端，登录/权限/数据全部以 mock 演示。运行时依赖为 vue 3.5.42、vue-router 5.3.0、pinia 4.0.3、element-plus 2.14.5、axios 1.20.0 与 echarts 6.1.0，工程化侧含 unocss 66 与 unplugin 自动导入/组件/EP 三件套按需引入。应用自 main.ts 的 bootstrap 启动，依次挂载插件、指令、Pinia 五仓库（app/setting/user/permission/tags-view）、异步路由后渲染，样式按 index.scss→uno.css→svg-icons 顺序注入。核心能力由 vue-router 守卫与静态/动态路由预留、v-roles/v-permissions 指令、五个全局组件（SvgIcon 及暂未接入业务页的 ProTable/ProPagination/ProChart/ProTooltip）、layout 布局（侧边栏、多标签、导航栏、设置抽屉、全站水印）构成。数据流上，登录写入 localStorage 的 accessToken，user 与 permission store 拉取 mock 信息生成菜单与动态路由；设置中心在 useTheme 的 View Transitions 回调内持久化，切 dark 类触发圆形扩散动效。已知边界：仅 gzip 预压缩、不引 brotli；i18n/ESLint/单测/CI 未做；refreshToken 仅前端预留；本机安全删除钩子 fail-closed，验证改动只用 vue-tsc -b；README 仍残留 oxfmt 与错误 Skill 列表两处过时信息。
