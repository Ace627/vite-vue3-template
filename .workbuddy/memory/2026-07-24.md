## SVG 图标插件替换：vite-plugin-svg-icons-ng → vite-plugin-svg-icons
- **背景**：`layout/index.vue` 的 SvgIcon 在 dev 下不显示。经多轮排查，原 `-ng` fork 在 dev 模式 sprite 注入/热更状态下出现 stale（旧 dev 进程 HTML 注入空容器、`<use>` 引用落空），机制不稳定。
- **决策**：用户要求移除 `vite-plugin-svg-icons-ng`，换原版 `vite-plugin-svg-icons` + `fast-glob`（fast-glob 本就在 devDeps）。
- **改动**：
  - `build/plugins/svg-icons-plugin.ts`：`createSvgIconsPlugin` 改从 `vite-plugin-svg-icons` 导入，symbolId 保持 `icon-[name]`；删掉注释掉的 `-ng` import。
  - `src/main.ts`：已有 `import 'virtual:svg-icons-register'`（原版插件运行时注入 sprite 的必需项，已就位）。
  - `package.json`：移除 `vite-plugin-svg-icons-ng`，保留 `vite-plugin-svg-icons ^2.0.1` 与 `fast-glob ^3.3.3`。
  - `docs/前端工程化.md`：SVG 章节措辞改为「运行时注入 sprite」。
  - 通过 PowerShell `& "C:\Progra~1\nodejs\pnpm.CMD" install` 同步 lockfile + node_modules，确认 `-ng` 目录与 lockfile 引用均清除。
- **验证**：
  - dev：`virtual:svg-icons-register` 返回 HTTP 200、`main.ts` 导入被正确改写为 `/@id/virtual:svg-icons-register`，server 启动零报错（Vite 8 兼容 OK）。
  - build：`vite build` 成功（1641 模块），打包 JS 含 `__svg__icons__dom__` 容器创建 + `createElementNS` 注入逻辑 + `icon-About` 等图标定义。
- **机制要点（防误判）**：原版插件**不把 symbol 写进静态 HTML**，而是由 `virtual:svg-icons-register` 运行时注入 DOM；故 curl 静态 HTML 或 dist 里 `#__svg__icons__dom__` 容器为空、symbol 数为 0 属**正常**，不等于 bug。
- **环境坑**：本机 `pnpm` 经 Git Bash 调 corepack 路径错写（`D:\c\Program Files\...`）；`cmd /c` 被沙箱安全策略拦截；可用 PowerShell 调 `& "C:\Progra~1\nodejs\pnpm.CMD" <cmd>` 正常执行。
