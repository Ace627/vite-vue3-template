## 抽离主题切换为 useTheme hook（修复设置页无动效）
- 根因：设置页原 `applyTheme` 虽调了 `document.startViewTransition`，但 `public/css/reset.css` 第28-31行把 `::view-transition-*` 的 `animation` 设为 `none`，而设置页未像 ThemeSwitch 那样补自定义 clipPath 动画，故被吃成瞬切（并非没调 API）。
- 新建 `src/hooks/useTheme.ts`：`useTheme()` 返回 `isDark` / `applyTheme(theme, event?)` / `toggleTheme(event?)`。统一：命令式切 `<html>.dark` + View Transitions 圆形扩散（有坐标从点击点、无坐标从屏幕中心扩散）+ `saveSetting({showTip:false})` + 防 FOUC 初始化；**含 `startViewTransition` 降级**（非 Chromium 直接切换，顺带修掉原 ThemeSwitch 无降级会崩溃的隐患）。沿用 `useDynamicTitle` 的无 import 风格（`src/hooks` 在 auto-import dirs）。
- `src/layout/components/Navbar/ThemeSwitch.vue`：删掉内部 startViewTransition/clipPath/animate 与初始化，改 `const { isDark, toggleTheme } = useTheme()`，`@click="toggleTheme"` 传 event。
- `src/views/settings/index.vue`：el-switch 由 `v-model+@change` 改为 `:model-value="isDark" @click="onThemeClick"`，`onThemeClick(event)` 调 `applyTheme(isDark?'light':'dark', event)` 实现从点击点扩散（按用户要求 click 触发拿坐标）；删除本地 `applyTheme`/`onThemeChange`。
- 验证：先 `vite build` 触发 auto-import 重新生成含 `useTheme` 的 d.ts，再 `pnpm build`（vue-tsc -b + vite build）exit 0 通过；d.ts 已确认注册 `useTheme`。

## 修复 useTheme 保存旧主题的 bug
- 根因：`applyTheme` 把 `settingStore.saveSetting(...)` 放在 `startViewTransition(run)` 之后**同步**调用，而 `run` 回调（含 `settingStore.theme = theme`）由浏览器异步执行，故 saveSetting 时 `state.theme` 仍是旧值 → `setSystemSetting(toRaw(state))` 持久化旧主题（表现等同"设置没保存"）。
- 修复：将 `settingStore.theme = theme` 与 `saveSetting` 一起移入 `run` 回调内（`startViewTransition` 的回调），确保持久化发生在主题值更新之后；降级分支同样在 `run()` 内完成。
- 验证：`pnpm build` exit 0 通过。

## 设置页改为「保存设置」按钮范式
- 用户纠正：原 size/动态标题 在 `@change` 即时 `saveSetting`（"不是这种改动生效的，是有一个保存设置的按钮"）；要求统一由「保存设置」按钮落盘。用户明确 `useTheme` 的 `saveSetting` 不变（即 theme 仍即时保存、不碰 hook）。
- `src/views/settings/index.vue`：删 size 的 `@change="onSizeChange"`、动态标题的 `@change="onSimpleChange"` 及对应即时 `saveSetting` 调用；底部新增「保存设置」按钮 `onSave`→`settingStore.saveSetting()`（默认 showTip 反馈）；「重置设置」保留→`resetSetting()`。`el-radio-group`/`el-switch` 用 `v-model` 直接绑 store，改动仅写 state（即时预览生效，不落盘）；theme 的 `@click="onThemeClick"` 仍调 `applyTheme`（即时保存，不动 useTheme）。
- 结论：设置页 theme 即时保存、size/动态标题 走保存按钮（因 useTheme 不变，未让 theme 也预览式）。若日后要 theme 也预览式需给 `applyTheme` 加可选 save 参数（会改 useTheme）。
- 验证：`pnpm build` exit 0 通过。

## Navbar 设置入口：router-link 改为 router.push（解决图标带蓝/变色）
- 根因：`<router-link>` 渲染成 `<a>`，`reset.css` 未重置 `<a>` color，浏览器默认链接蓝 + `:hover`/`:active` 变色，经 `currentColor` 传染给 `<SvgIcon>`（组件 fill 依赖 currentColor）。`ThemeSwitch` 不在 `<a>` 内故正常，反证此因。
- 修复：`src/layout/components/Navbar/index.vue` 把设置入口由 `<router-link to="/settings">` 改为 `<span class="navbar-item hover-effect" @click="goSettings">`；脚本加 `const router = useRouter()` + `goSettings(){ router.push('/settings') }`（useRouter 已 auto-import，vue-router 在 auto-import imports）。替换后无 `<a>`，图标 inherit 文字色，随主题变化。
- 验证：`pnpm build` exit 0 通过。
