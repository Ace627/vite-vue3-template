## 对比研究 vbenjs/vite-plugin-html 官方实现

- 用户想看官方实现。结论：它是 pnpm monorepo（`packages/core`），`createHtmlPlugin()` 组合 `createPlugin(htmlPlugin.ts)` + `createMinifyHtmlPlugin(minifyHtml.ts)` 两个插件。
- 占位符机制用 **EJS 模板引擎**（`import { render } from 'ejs'`）：`renderHtml` 把 `viteConfig.env` + `viteConfig.define` + `loadEnv()` + `inject.data` 合并成 `ejsData`，再 `render(html, ejsData, ejsOptions)`。HTML 里写 EJS 语法 `<%- title %>`、**不是** Vite 原生 `%VAR%`、也不是正则。
- 钩子：`name: 'vite:html'`、`enforce: 'pre'`，`transformIndexHtml`（Vite>=5 用 `{order:'pre', handler}`）；另含 `configResolved`(loadEnv)、`config`(MPA 的 rollup input)、`configureServer`(history fallback)、`closeBundle`(搬 html 到 outDir 根)。
- 能力：EJS 模板、多页 MPA、自定义 entry（注入 module script 并删原脚本）、tags 注入、HTML minify(html-minifier-terser)、SPA history。
- 依赖：`ejs`、`node-html-parser`、`fs-extra`、`pathe`、`fast-glob`、`consola`、`colorette`、`connect-history-api-fallback`。
- 结论：我们「不装 vben、手搓借名」的取舍合理——vben 是整套 HTML 工程化方案（且用 EJS 需改 HTML 语法、引入 ejs 等依赖），我们只需 meta 注入，手搓方案用 Vite 8 原生 `%VITE_*%` + 极简 map（~15 行、0 依赖），更轻且天然契合「单一真源 + 原生风格」约定。
