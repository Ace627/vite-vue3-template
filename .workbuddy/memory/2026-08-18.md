## 修复 TagsView 删除缓存不一致（同日下午，用户确认落地）
- 问题1（本次新增功能的 bug）：关闭左/右侧后，`delRight/LeftCachedViews` 在 `visitedViews` 已被 `delRight/LeftVisitedViews` 改动后重算 index，导致 `i>index`/`i<index` 命中空集合 → 被关标签的 keepAlive 缓存名残留。
- 问题2（既有）：`delOthersCachedViews`/`delAllCachedViews` 未保留 affix 固定页缓存名（含 `view.name` 为 undefined 时误清空全部缓存的边界 bug）。
- 方案：store 内把左右删除改为原子方法 `delLeftTags`/`delRightTags`（先算 removedNames 再删 visited+cache）；`delOthersCachedViews`/`delAllCachedViews` 改为按 affix+当前页保留缓存名。导出表移除 4 个旧方法、加入 `delLeftTags`/`delRightTags`；组件 `closeLeft/RightTags` 改调原子方法。
- 验证：`vue-tsc -b` 通过；`vite build --outDir dist-verify` 构建通过（旧 `dist/` 因安全删除钩子无法 trash，环境问题）。`dist-verify` 临时目录因安全删除批量确认未自动删除，需手动清理。
