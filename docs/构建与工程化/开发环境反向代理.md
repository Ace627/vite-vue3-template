# 开发环境反向代理

## 功能定位

开发期借助 Vite 内置 dev server 的 `server.proxy`，将前端发往「代理前缀 + 后端公共路径」的请求，在 Node 侧转发到真实后端，从而**在浏览器侧消除跨域**。生产构建产物不含代理逻辑，由 nginx / 网关等同域反向代理接管。

## 实现要点

| 落地点 | 职责 |
| --- | --- |
| `vite.config.ts` 的 `server.proxy` | 代理核心配置；以 `VITE_BASE_API` 作匹配前缀，`target` 指向 `VITE_BASE_URL`，`changeOrigin: true`，`rewrite` 剥离 `/dev-api` |
| `.env.development` | `VITE_BASE_URL="http://localhost:3000"`（后端地址）、`VITE_BASE_API="/dev-api/api"`（触发前缀 `/dev-api` + 后端路径 `/api`） |
| `.env.production` | 仅 `VITE_BASE_API="/api"`，**不设 `VITE_BASE_URL`**（生产无代理目标） |
| `src/utils/request/index.ts` | axios `baseURL: import.meta.env.VITE_BASE_API`，请求前缀由环境变量驱动 |
| `src/types/global/vite-env.d.ts` | 声明 `VITE_BASE_URL` / `VITE_BASE_API`，提供 TS 类型提示 |

### 机制

开发期一次请求 `/dev-api/api/xxx` 的流转：

```
浏览器 ──(同源 localhost:5173，无 CORS)──▶ Vite dev server
        proxy 匹配 /dev-api/api
        → changeOrigin 改写 Host
        → rewrite 剥离 /dev-api
        ──▶ http://localhost:3000/api/xxx   (Node 侧转发，不受浏览器跨域限制)
```

关键设计：**`VITE_BASE_API` 把「代理触发前缀 `/dev-api`」与「后端公共路径 `/api`」合一**：
- 开发期值为 `/dev-api/api` → 命中代理、剥离 `/dev-api` → 后端收到 `/api/...`；
- 生产期值为 `/api`（无 `/dev-api`）→ 不触发代理，请求同源直连 `/api`。

## 好处

- **开发期零跨域**：浏览器只与同源 dev server 通信，跨域发生在服务端，无需后端开 CORS、无需浏览器插件。
- **切环境 / 换后端只动 `.env`**：业务代码与 axios 实例零改动；新增后端公共路径只需在 `/dev-api` 后追加（如 `/dev-api/common`）。
- **触发前缀与后端路径统一于单变量**，配置心智简单，不易配错。
- **后端无公共路径时零配置即代理生效**：`VITE_BASE_API` 同时驱动「代理匹配键」「axios baseURL」「rewrite 剥离」三处；当后端没有公共路径（如接口即 `/user/list`，非 `/api/user/list`）时，只需把值写成 `/dev-api`（去掉 `/api` 段），代理匹配键与 baseURL 同步变为 `/dev-api`、rewrite 剥离 `/dev-api` 后转发到 `localhost:3000/user/list`，**全过程不碰 `vite.config.ts`、不改 axios、不改 rewrite**——一处去段、全局自动生效。

## 工程化好处

- **关注点分离**：网络转发配置与业务请求代码解耦，前端无需感知后端部署地址。
- **环境隔离**：dev（代理转发）与 prod（同源直连）由 `.env` 分流；代理逻辑不进入生产包，产物更干净。
- **可复制标准范式**：Vite dev proxy 是业界通用做法，新人可照此直接对接任意后端。
- **类型安全**：`vite-env.d.ts` 对两个变量做了声明，避免拼写 / 取值错误。

## 注意事项

- **Vite 代理仅开发期生效**；生产环境必须由 nginx / 网关等做同域反向代理（`.env.production` 的 `/api` 直连同源后端或网关）。
- **`VITE_BASE_URL` 仅 dev 存在**；生产不应设置，否则无意义。
- **`rewrite` 只剥离 `/dev-api`**：若后端公共路径不是 `/api`，需同时修改 `.env.development` 与 `.env.production` 的 `VITE_BASE_API`，保持两侧一致。
- **`changeOrigin: true` 务必开启**，否则部分后端会按 `Host` 头拒绝请求。
- **项目边界提示**：本项目定位「纯前端 mock，不接后端」，当前 `VITE_BASE_URL` 的 `localhost:3000` 为模板占位；切换真实后端时改 `.env` 即可，业务代码无需改动。
