# 设备自适应（响应式断点）

## 功能定位

用单一 `html[data-device]` 断点信号驱动全站移动端适配：JS 仅检测一次窗口宽度，全站响应式靠 CSS 属性选择器声明式响应，组件无需各自判断窗口。

## 实现要点

| 文件 | 职责 |
|---|---|
| `src/hooks/useResize.ts` | 监听 `resize` 与路由变化，阈值 `992px` 判定 `mobile`/`desktop`，写 `appStore.device` 并同步 `html[data-device]` |
| `src/store/modules/app.ts` | `device` 字段 + `isMobile`/`isDesktop` computed + `closeSidebar`（移动端折叠侧栏） |
| `src/App.vue` | 根组件调用 `useResize()` 启用 |
| `src/styles/index.scss` 及各页面 | `html[data-device='mobile']` 覆盖样式（`.app-content` 收窄、设置页堆叠、404 页等） |

机制：

- `useResize` 在 `onBeforeMount` 注册 `resize` 监听、`onMounted` 立即判定一次、`onBeforeUnmount` 移除；`document.hidden` 时跳过，避免后台冗余计算。
- 判定：`document.body` 宽度 `< 992px` 视为 mobile，写入 `appStore.device` 并 `document.documentElement.dataset.device = device`，全站 CSS 据此响应。
- 路由切换时（watch `route.name`）移动端自动调整侧栏折叠状态。

## 好处

- **断点集中**：阈值只在一处定义，改一处全站生效；以后要加移动端适配点，只补一条 CSS 就行，风格自然统一。
- **声明式响应**：组件不用写窗口判断，纯 CSS `html[data-device='mobile']` 覆盖，逻辑与样式解耦。
- **无重复监听**：单例 hook 在根组件启用，全局共享同一个信号。
- **接入状态层**：设备类型进了 Pinia（`device`），需要时被 JS 逻辑消费，比如侧栏折叠。

## 注意事项

- 阈值当前为 `992px`（参考 Bootstrap 响应式断点）；如需调整改 `useResize.ts` 的 `MAX_MOBILE_WIDTH` 一处即可。
- `useResize()` 须在根组件（`App.vue`）调用一次，重复调用会重复注册监听。
- CSS 覆盖统一用 `html[data-device='mobile']` 前缀，不要在组件内联判断窗口宽度。
- 后台标签页（`document.hidden`）下 `resize` 不触发，切回前台后的首次 `resize` 才更新。
