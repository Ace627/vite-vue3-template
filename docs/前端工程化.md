# 前端工程化配置

> 基于 `pnpm create vite` 的 Vue3 + TS 模板二次改造，以下为已实现的工程化配置。每条后用一句话说明它带来的好处。

## 一、构建与产物优化

- **构建期 vendor chunk 分包（Rolldown `codeSplitting.groups`）**：把 `vue/pinia/vue-router/axios/dayjs` 拆成独立带 hash 的 chunk，库代码不随业务发版变动，二次访问命中浏览器长缓存、免重下，首屏多块并行下载更快。
- **构建期 gzip 预压缩（vite-plugin-compression2）**：对 >10KB 的 JS/CSS/JSON/HTML/SVG 生成 `.gz` 预压缩文件（保留原文件），传输体积降约 61%（vue 60.7KB→23.6KB、vue-router 22.7KB→8.9KB），首屏大资源下载更快；压缩成本前移到构建期、零运行时开销，服务端开 `gzip_static` 即直接发 `.gz`。
- **构建期移除 console/debugger**：通过 Rolldown `minify.compress.dropConsole/dropDebugger` 在打包时剔除调试语句，生产包更干净、体积更小（可用 `VITE_DROP_*` 关闭）。
- **Vite 插件抽离**：vue / UnoCSS / 自动导入 / SVG 等插件统一在 `build/plugins/index.ts` 注册，配置集中可维护，且纳入 `tsconfig.node` 类型检查。

## 二、类型与代码质量

- **严格 TypeScript 配置**：开启 `noUnusedLocals/Parameters`、`erasableSyntaxOnly`，`tsconfig.node` 用 `verbatimModuleSyntax/nodenext`，编译期即拦掉未用变量与错误模块写法，减少低级 bug。
- **oxfmt 统一格式化**：固定 `printWidth/singleQuote/semi/sortImports` 等规则并启用 import 排序，团队提交风格一致，`format:check` 可作格式门禁。
- **脚手架清理**：移除 Vite 默认样板冗余，保留最小可运行骨架，模板更干净、上手更快。

## 三、开发体验

- **路径别名 `@/*`**：`@` 直指 `src`，深层引用不再写 `../../`，且 tsconfig 与 vite alias 双向同步，IDE 跳转与构建都认。
- **unplugin 自动导入**：`vue/pinia/vue-router` 及 `store/modules`、`hooks` 免手写 import，减少样板、避免遗漏。
- **开发期反向代理 `/dev-api`**：把「代理触发前缀」与「后端公共路径」合一于 `VITE_BASE_API` 一个变量，开发消跨域、切环境/换后端只动 `.env`，业务代码零改动。
- **多环境 `.env`**：dev/prod 分别提供后端地址、超时、丢弃调试等变量，`index.html` 用 `%VITE_APP_TITLE%` 原生注入，环境切换零代码改动。

## 四、状态管理与路由

- **Pinia 状态管理**：`createPinia()` 单例 + `setupStore(app)` 统一装配，状态层结构清晰、便于测试与维护。
- **vue-router + 404 兜底**：`setupRouter(app)` 异步装配并含 404 兜底路由；`VITE_ROUTER_MODE` 切换 hash/history，路由能力开箱即有。

## 五、请求层

- **axios 请求层**：统一实例 + `jwt-auth` / `response-transform` / `response-error` 三拦截器，成功自动解包 `data`、业务失败与 401 自动清 token 刷新；`ApiResponse<T>` 契约让调用方直接 `get<User>` 拿到业务数据，类型全程收紧。

## 六、样式与 UI

- **UnoCSS**：`presetWind3 + presetAttributify` + 自定义 rules/shortcuts，原子化开发、编译期摇树，无运行时 CSS 框架体积。
- **样式分层（reset.css）**：`reset.css` 经 `<link>` 引入不进打包，避免 FOUC（样式闪烁），全局样式入口 `index.scss` 独立清晰。
- **SVG 图标（SvgIcon）**：`vite-plugin-svg-icons-ng` inline 注入 sprite，组件按文件名引用图标；新增图标走清理脚本适配 `currentColor`，单色图标随主题变色。

## 七、首屏体验

- **首屏加载动画（白屏兜底）**：`#app` 内放纯 HTML+CSS spinner，`main.ts` 不手动删节点，靠 `app.mount` 原生清空自动消失，JS 加载期间不再白屏、体验更顺。

## 八、工程化 Skill

- **3 个项目 Skill（git-commit-msg / path-alias / add-global-component）**：把「提交规范」「别名配置」「新增全局组件」等固定流程沉淀为可复用技能，照着走不踩坑、减少重复决策。
