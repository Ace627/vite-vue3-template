# 导航栏与用户菜单（Navbar）

## 功能定位

顶部导航栏，承载「侧栏折叠、系统设置入口、主题切换、用户菜单」四类交互。

## 实现要点

| 落地点 | 职责 |
| --- | --- |
| `src/layout/components/Navbar/index.vue` | Navbar 视图：左侧 `Hamburger`，右侧 `设置入口（齿轮）` + `ThemeSwitch` + `UserDropDown` |
| `src/layout/components/Navbar/Hamburger.vue` | 侧栏折叠按钮：`@toggleClick` 调 `appStore.toggleSidebar`，折叠态持久化到 `sidebar-status.cache` |
| `src/layout/components/Navbar/ThemeSwitch.vue` | 明暗切换按钮，委托 `useTheme().toggleTheme` |
| `src/layout/components/Navbar/UserDropDown.vue` | 用户下拉菜单：头像（`userStore.avatar`）+ 昵称 + 问候语 + 菜单项（系统设置 / 退出登录） |

## 关键点

- **设置入口**：Navbar 齿轮图标与 `UserDropDown` 的「系统设置」菜单项，均将 `settingStore.showSetting` 置 `true`，唤起 `SettingPanel` 抽屉（见 `../构建与工程化/全局设置中心.md`）。
- **主题切换**：`ThemeSwitch` 复用 `useTheme()` 统一逻辑层（见 `../用户体验/主题切换.md`）。
- **用户菜单**：「退出登录」调 `userStore.logout()` 清 token 并 `router.replace('/login')`；头像缺失时回退 `default-avatar.jpg`。
- **移动端**：`appStore.isMobile` 时侧栏以抽屉形式从左侧滑出，Navbar 的 `Hamburger` 控制开合，遮罩层点击关闭（见 `src/layout/index.vue`）。

## 注意事项

- 图标统一用 `<SvgIcon>`（如齿轮 `Setting`、退出 `Logout` 等），遵守 AGENTS.md。
- 导航栏交互均改动 `appStore` / `settingStore` / `userStore`，不直写 `localStorage`。
