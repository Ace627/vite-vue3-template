# 权限指令（v-roles / v-permissions）

## 功能定位

基于当前用户「角色 / 权限」控制 DOM 元素显隐的自定义指令，无权限时直接移除元素。当前角色与权限来自 mock 登录信息（`userStore.getInfo` 返回的写死数据）。

## 实现要点

| 落地点 | 职责 |
| --- | --- |
| `src/directives/index.ts` | `setupDirectives(app)`：`app.directive('roles', roles)` / `app.directive('permissions', permissions)` |
| `src/directives/modules/roles.ts` | `v-roles`：绑定角色数组，用户 `roles` 不含任一则移除元素 |
| `src/directives/modules/permissions.ts` | `v-permissions`：绑定权限编码数组，用户 `permissions` 不含任一则移除元素 |
| `src/types/global/directive.d.ts` | 声明 `GlobalDirectives` 的 `vRoles` / `vPermissions` 类型（绑定值强制 `string[]`） |
| `src/main.ts` | 启动时调用 `setupDirectives(app)` 注册 |

## 用法

```vue
<button v-permissions="['system:user:add']">新增用户</button>
<button v-roles="['admin']">管理员操作</button>
```

## 关键点

- **fail-soft**：绑定值非数组或空数组时仅 `console.warn` 告警并跳过校验，不抛错、不移除元素。
- **数据来源**：指令读取 `useUserStore()` 的 `roles` / `permissions`，由 `getInfo()` 从 mock 数据填充。
- **类型安全**：`directive.d.ts` 约束绑定值为 `string[]`，传非数组编译报错。

## 注意事项

- 纯前端演示：角色 / 权限是 `auth.request.ts` 返回的写死数据，接真实后端放开 `getInfo` 的 `request.*` 调用即生效。
- 指令只控制显隐，不替代路由级权限（`router.guard` 的登录态 + 角色校验）。
