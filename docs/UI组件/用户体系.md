# 用户体系（mock 实现）

## 功能定位

前端模拟的登录态与用户信息体系，覆盖「获取验证码 → 登录 → 拉取用户信息（角色/权限）→ 退出」整链。纯前端工程化样本，**不调真实后端**。

## 实现要点

| 落地点 | 职责 |
| --- | --- |
| `src/api/auth.request.ts` | `AuthRequest` 抽象类：`getCaptcha` / `login` / `getInfo` / `logout` 均返回写死数据（`request.*` 调用已注释，零网络请求） |
| `src/store/modules/user.ts` | `useUserStore`：`currentUserInfo` / `roles` / `permissions` / `avatar` + `login` / `getInfo` / `logout` |
| `src/views/core/login.vue` | 登录页：验证码 + 账号密码 + 「记住密码」（`login-params.cache` 缓存用户名密码），提交后写 token 并 `getInfo` |
| `src/utils/cache/login-params.cache.ts` | `setLoginParams` / `getLoginParams` / `removeLoginParams`（记住密码） |
| `src/utils/time.ts` | `getTimeGreeting`：按当前小时返回「上午好 / 中午好 / 下午好 / 晚上好」等问候语 |
| `src/router/router.guard.ts` | 已登录但无 `roles` 时 `userStore.getInfo()` + `permissionStore.getRoutes()` 生成路由 |

## 关键点

- **登录态本质**：`localStorage` 的 `accessToken` 即全部登录态（同此前约定），`login` 写死 token、`logout` 清 token。
- **用户信息**：`getInfo` 返回 `CurrentUserInfo`（`user` / `roles` / `permissions`），驱动权限指令与用户菜单。
- **记住密码**：勾选后 `login-params.cache` 持久化用户名密码，下次进入登录页自动回填。
- **问候语**：用户菜单可基于 `getTimeGreeting()` 展示时段问候（如「上午好，管理员」）。

## 注意事项

- 账号密码 / 验证码**不校验**，角色权限为 mock 数据；接真实后端只需放开 `auth.request.ts` 内被注释的 `request.*` 调用，并保留 `user` store 与权限指令。
- 路由级权限：`router.guard` 已具备「无角色 → 拉信息 → 生成路由」分支，动态路由（`asyncRoutes`）接真接口为预留。
