# 多标签页面签（TagsView）

## 功能定位

顶部的多标签导航，记录已访问路由，支持关闭、关闭其他、关闭全部，并维护 `KeepAlive` 缓存名单（预留）。

## 实现要点

| 落地点 | 职责 |
| --- | --- |
| `src/layout/components/TagsView/index.vue` | 页签栏视图：渲染 `visitedViews`，提供关闭 / 右键菜单（关闭其他、关闭全部） |
| `src/store/modules/tags-view.ts` | `visitedViews` / `cachedViews` 及增删操作，`watchEffect` 自动持久化 |
| `src/utils/cache/tags-view.cache.ts` | `setVisitedViews` / `getVisitedViews` / `setCachedViews` / `getCachedViews`（基于 `StorageCache`） |
| `src/defaultSettings.ts` | `showTagsView`（是否显示页签）、`showTagsViewIcon`（是否显示页签图标） |

## 关键点

- **显隐**：`layout/index.vue` 中 `<TagsView v-if="settingStore.showTagsView" />` 受设置开关控制。
- **图标**：页签图标取路由 `meta.icon`，经 `<SvgIcon>` 渲染（`showTagsViewIcon` 控制）。
- **持久化**：`visitedViews` / `cachedViews` 经 `watchEffect` 写入 `StorageCache`，刷新后还原。
- **缓存名单**：`cachedViews` 收集 `meta.keepAlive` 为 `true` 的组件 `name`，供 `AppMain` 的 `KeepAlive :include` 使用（当前 `AppMain` 的 `KeepAlive` 仍为占位空数组，缓存能力待接入）。

## 注意事项

- `addVisitedView` 对路径含 `analysis` 的临时跳过（后续按菜单实体调整）。
- 页签 `affix: true` 的路由（如首页）在「关闭其他 / 关闭全部」时保留。
