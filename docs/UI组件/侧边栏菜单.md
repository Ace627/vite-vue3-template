# 侧边栏菜单（Sidebar）

## 功能定位

基于 `permissionStore.sidebarRoutes` 渲染的左侧导航菜单，是 Layout 的固定侧栏。菜单数据当前来自静态路由，动态路由（接真接口）预留。

## 实现要点

| 落地点 | 职责 |
| --- | --- |
| `src/layout/components/Sidebar/index.vue` | Sidebar 视图：顶部 `AppLogo`（受 `showLogo` 控制）+ `el-scrollbar` 包裹 `el-menu` |
| `src/layout/components/Sidebar/SidebarItem.vue` | 递归菜单项：SvgIcon 图标 + 标题 + 子菜单，支持 `hidden` / `activeMenu` / 外链 |
| `src/store/modules/permission.ts` | `sidebarRoutes`：当前 `getRoutes()` 仅合并 `STATIC_ROUTE_LIST`，动态路由预留 |
| `src/router/router.helper.ts` | `resolvePath` / `normalizePath`：菜单项路径拼接与绝对外链判断 |

## 关键点

- **图标**：菜单图标取自路由 `meta.icon`，经 `<SvgIcon :name="meta.icon">` 渲染（遵守 AGENTS.md，统一 SvgIcon 来源；缺省回退 `Key`）。
- **折叠**：`appStore.isCollapse` 驱动 `el-menu` `collapse`，`AppLogo` 同步只显示图标（`show-title="!isCollapse"`）。
- **手风琴**：`settingStore.uniqueOpened` 控制 `el-menu` 的 `unique-opened`。
- **Logo 显隐**：`settingStore.showLogo` 控制侧栏顶部 `AppLogo` 是否渲染。
- **激活态**：`default-active` 取 `route.meta.activeMenu || route.path`，支持详情页高亮父菜单。
- **路由跳转**：菜单项点击经 `resolvePath` 拼接路径，`isExternal` 外链新窗口打开，否则 `router.push`。

## 注意事项

- 当前 `sidebarRoutes` 仅含静态路由（`dashboard`），新增业务页在 `static.route.ts` 的 `STATIC_ROUTE_LIST` 加 children 即可上菜单；动态权限菜单待接真实后端后由 `permissionStore.getRoutes()` 注入。
- 菜单项 `meta.hidden` 为 `true` 时不渲染（如 login / 404 / redirect）。
