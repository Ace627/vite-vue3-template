# 系统级水印

## 功能定位

在布局根层用 `<el-watermark>` 把整个应用包起来，全站业务页自动带水印，业务代码完全不用管。`content` 受「系统水印」开关控制，`font` 跟着主题明暗走。关掉时只留一层空的、不渲染水印内容。

## 实现要点

| 落地点 | 职责 |
| --- | --- |
| `src/layout/index.vue` | `<el-watermark>` 包裹 `Navbar` + `AppMain` 整层；`content` 绑 `computed(() => showWatermark ? VITE_APP_TITLE : [])`，`font` 绑 `isDark` |
| `src/store/modules/setting.ts` | `showWatermark` 状态（见 `../构建与工程化/全局设置中心.md`） |
| `src/layout/components/SettingPanel/index.vue` | 「系统水印」开关 `v-model="settingStore.showWatermark"`，即时生效 |
| `src/hooks/useTheme.ts` | 提供 `isDark` 驱动水印字体明暗 |

## 机制

- 单个 `el-watermark` 在 layout 根层声明一次，覆盖所有业务页，不用每页各自加。
- `content`：`showWatermark` 为真取 `VITE_APP_TITLE`，否则传空数组 `[]`——层留着、水印内容不渲染，避免布局跳动。
- `font`：`computed` 绑 `isDark`，暗色 `rgba(255,255,255,.15)` / 亮色 `rgba(0,0,0,.15)`，`el-watermark` 内部 watch 随主题重绘。
- `gap=[16,16]` 控制平铺密度，`class="wh-full"` 铺满；默认 `z-index:9` 低于 EP 弹窗（2000+），不挡对话框。

## 好处

- **一套覆盖全站**：在 layout 层声明一次，所有页面都有，业务页不用碰。
- **即时开关**：SettingPanel 抽屉里一拨就生效，响应式驱动。
- **跟主题走**：字体色随主题变，暗色下也不扎眼。
- **不挡弹窗**：默认 `z-index` 低于 EP 弹窗。

## 工程化好处

- **封装在布局层**：水印放在 layout 层而不是业务层，关注点分开。
- **配置驱动**：显不显示由 `SystemSetting` 控制，复用统一设置体系（见 `../构建与工程化/全局设置中心.md`）。
- **接入零成本**：就是 `el-watermark` 的标准用法，组件经 `unplugin-vue-components` + `ElementPlusResolver` 按需解析，类型自动注册成 `ElWatermark`。

## 注意事项

- 关掉时 `content=[]` 而不是移除那一层，免得布局跳动。
- 水印必须绑在 layout 根上才覆盖全站；绑到业务页里只对该页生效。
- 字体色随 `isDark`，得在 layout 里从 `useTheme()` 取 `isDark`（已经在布局取了）。
- 站点名统一来自 `VITE_APP_TITLE`（与 `index.html` 的 `%VITE_APP_TITLE%`、AppLogo 默认 `title` 同源）。
