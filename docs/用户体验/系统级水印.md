# 系统级水印

## 功能定位

在布局根层以 `<el-watermark>` 包裹整个应用，全站业务页自动带水印、业务代码零侵入。`content` 受「系统水印」开关控制，`font` 随主题明暗联动。关闭时不渲染水印内容、仅留无害空层。

## 实现要点

| 落地点 | 职责 |
| --- | --- |
| `src/layout/index.vue` | `<el-watermark>` 包裹 `Navbar` + `AppMain` 整层；`content` 绑 `computed(() => showWatermark ? VITE_APP_TITLE : [])`，`font` 绑 `isDark` |
| `src/store/modules/setting.ts` | `showWatermark` 状态（见 `../构建与工程化/全局设置中心.md`） |
| `src/views/settings/index.vue` | 「系统水印」开关 `v-model="settingStore.showWatermark"`，即时生效 |
| `src/hooks/useTheme.ts` | 提供 `isDark` 驱动水印字体明暗 |

## 机制

- 单一 `el-watermark` 在 layout 根层声明一次，覆盖所有业务页（不在每页各自加水印）。
- `content`：`showWatermark` 为真取 `VITE_APP_TITLE`，否则传空数组 `[]`——保留层、不渲染水印内容，避免布局跳动。
- `font`：`computed` 绑 `isDark`，暗色 `rgba(255,255,255,.15)` / 亮色 `rgba(0,0,0,.15)`，`el-watermark` 内部 watch 随主题重绘。
- `gap=[16,16]` 控制平铺密度，`class="wh-full"` 铺满；默认 `z-index:9` 低于 EP 弹窗（2000+），不遮挡对话框。

## 好处

- **全站统一**：一处声明覆盖所有页面，业务页零侵入。
- **开关即时**：设置页切换即时生效（响应式驱动）。
- **明暗联动**：字体色随主题，暗色下不突兀。
- **不遮挡**：默认 `z-index` 低于 EP 弹窗。

## 工程化好处

- **布局级封装**：水印在 layout 层而非业务层，契合关注点分离。
- **配置驱动**：是否显示由 `SystemSetting` 控制，复用统一设置体系（见 `../构建与工程化/全局设置中心.md`）。
- **可复制**：`el-watermark` 标准用法，接入零成本（组件经 `unplugin-vue-components` + `ElementPlusResolver` 按需解析，类型自动注册 `ElWatermark`）。

## 注意事项

- 关闭时 `content=[]` 而非移除层，避免布局跳动。
- 必须与 layout 根绑定才能覆盖全站；在业务页内加只作用于该页。
- 字体色随 `isDark`，需在 layout 内从 `useTheme()` 取 `isDark`（已在布局取）。
- 站点名统一来源 `VITE_APP_TITLE`（与 `index.html` 的 `%VITE_APP_TITLE%`、AppLogo 默认 `title` 同源）。
