# 首屏加载动画（白屏阶段 CSS Loading）

## 功能定位

Vue 应用启动前，用**纯 HTML + CSS** 放一个加载动画，盖住 JS 下载到挂载这段空窗，免得首屏白屏。

## 实现要点

| 文件 | 职责 |
|---|---|
| `index.html` | 在 `#app` 内预置 `.app-loading` 结构，并通过 `<link>` 引入 `app-loading.css`；`main.ts` 以模块脚本（默认 defer）加载 |
| `public/css/app-loading.css` | 全屏居中动画；放 `public/` 不经打包，原样输出到 `/css/` |
| `src/main.ts` | `app.mount('#app')` 时 Vue 整体替换 `#app` 内容，`.app-loading` 节点随之销毁 |

机制：`type="module"` 脚本默认 defer，浏览器先渲染 HTML 中的 loading 结构；`app.mount` 后用应用内容整体替换 `#app`，动画自然消失。

## 这么做的好处

- **不白屏**：动画在 HTML 解析阶段就由浏览器原生渲染，不依赖任何 JS 框架，首屏立刻有反馈。
- **不阻塞**：模块脚本默认 defer，CSS 走 `<link>` 同步加载，不影响首屏；动画和业务代码互不干扰。
- **不用手动清理**：随 `app.mount` 被整体替换，没有额外的 DOM 操作，也不会和 Vue 挂载打架。
- **好改**：文案读 `.env` 的 `VITE_APP_TITLE`，配色和动画都收在一个 CSS 文件里。

## 对工程化的好处

- **资源隔离**：首屏用的静态资源走 `public/` + `<link>`，不进打包链路，不污染构建产物。
- **和 reset.css 同一套路**：都是静态资源 `<link>` 引入、不进打包，首屏渲染方式保持一致。
- **能直接抄**：模板已经把首屏 loading 的写法定死了，新项目照着放文件就行。
- **零运行时依赖**：纯 CSS，不增加包体。

## 注意事项

- CSS 必须放 `public/` 走 `<link>` 引入，**不能** import 进 `main.ts`，否则就起不到白屏阶段的作用。
- `%VITE_APP_TITLE%` 由 Vite 构建时替换，dev 环境取 `.env.development`。
- `app-loading.css` 当前未被 `oxfmt.config.ts` 忽略，跑 `pnpm format` 会被格式化；要排除就在 `ignorePatterns` 里加上它。
