# 首屏加载动画（白屏阶段 CSS Loading）

## 功能定位

在 Vue 应用启动前，用**纯 HTML + CSS** 展示一个加载动画，覆盖 JS 资源下载与挂载之间的空窗期，避免首屏白屏。

## 实现要点

| 文件 | 职责 |
|---|---|
| `index.html` | 在 `#app` 内预置 `.app-loading` 结构，并通过 `<link>` 引入 `app-loading.css`；`main.ts` 以模块脚本（默认 defer）加载 |
| `public/css/app-loading.css` | 全屏居中动画；放 `public/` 不经打包，原样输出到 `/css/` |
| `src/main.ts` | `app.mount('#app')` 时 Vue 整体替换 `#app` 内容，`.app-loading` 节点随之销毁 |

机制：`type="module"` 脚本默认 defer，浏览器先渲染 HTML 中的 loading 结构；`app.mount` 后用应用内容整体替换 `#app`，动画自然消失。

## 这么做的好处

- **消除白屏 / 抗 FOUC**：动画在 HTML 解析阶段即由浏览器原生渲染，不依赖任何 JS 框架，用户首屏立刻看到反馈而非空白。
- **零阻塞**：模块脚本默认 defer，CSS 经 `<link>` 同步加载，不拖累首屏；动画与业务代码完全解耦。
- **零成本移除**：随 `app.mount` 自然被替换，无需手动 DOM 操作，不会与 Vue 挂载冲突。
- **可定制**：文案取自 `.env` 的 `VITE_APP_TITLE`，配色 / 动画集中于单一 CSS 文件。

## 对工程化的好处

- **关注点分离**：静态首屏资源独立于打包链路（`public/` + `<link>`），不污染构建产物，也不参与模块图。
- **防 FOUC 设计一致性**：与 `public/css/reset.css` 同思路（静态资源 `<link>` 引入、不进打包），形成统一的"首屏稳定渲染"约定。
- **可复制的标准实践**：作为模板，给出"首屏 loading 怎么做"的最小可行范式，AI 或协作者可直接参照落地，无需从零决策。
- **零运行时依赖**：纯 CSS 实现，不增加任何包体，契合"纯前端工程化、轻量"的定位。

## 注意事项

- 必须放 `public/` 经 `<link>` 引入，**不能** import 进 `main.ts`（否则失去白屏阶段意义）。
- `%VITE_APP_TITLE%` 由 Vite 构建时替换，dev 环境取 `.env.development`。
- `app-loading.css` 当前未被 `oxfmt.config.ts` 忽略，执行 `pnpm format` 会被格式化；如需排除，在 `ignorePatterns` 加入 `app-loading.css`。
