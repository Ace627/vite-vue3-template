# 动态标题（Dynamic Document Title）

## 功能定位

路由切换时，根据当前页面自动更新浏览器标签页标题（格式：`页面名 - 站点名`），并支持在设置页开关与持久化。

## 实现要点

| 文件 | 职责 |
|---|---|
| `src/hooks/useDynamicTitle.ts` | 核心：watch 路由 `path` 与 `showDynamicTitle`，据此写 `document.title` |
| `src/App.vue` | 根组件调用 `useDynamicTitle()` 启用（应用级单例） |
| `src/store/modules/setting.ts` | 暴露响应式 `showDynamicTitle` 状态 |
| `src/defaultSettings.ts` | 默认 `showDynamicTitle: true`（默认开启） |
| `src/views/settings/index.vue` | 开关 UI：`<el-switch v-model="settingStore.showDynamicTitle" />` |
| `src/router/modules/static.route.ts` | 路由 `meta.title` 提供各页面名称 |

机制：`useDynamicTitle()` 内 `watch([route.path, showDynamicTitle], ..., { immediate: true })`。开启且路由声明了 `meta.title` 时标题为 `页面名 - 站点名`；否则（关闭或未声明）回退为纯站点名（取自 `VITE_APP_TITLE`）。

## 这么做的好处

- **多页可区分**：多标签 / 多窗口下用户一眼识别当前所在页面。
- **可配置**：用户在设置页即时开关，并经 store 落盘持久化，不强加。
- **声明式**：页面标题写在路由 `meta`，不在组件内散落维护。
- **轻量**：直接操作 `document.title`，无额外 DOM 结构、无新增依赖。

## 对工程化的好处

- **关注点分离**：标题逻辑集中于一个 hook，页面只负责在路由 `meta` 声明名称。
- **配置中心化**：`showDynamicTitle` 纳入 `SystemSetting`，与主题 / 水印 / 尺寸统一由同一 store 管理，复用同一套保存 / 重置流程。
- **易于扩展**：新增页面只需在路由 `meta` 加 `title`，hook 与 UI 均无需改动。
- **与设置体系一致**：复用既有开关组件与 `saveSetting` 持久化，不另造轮子。

## 注意事项

- 站点名取自 `VITE_APP_TITLE`（`.env` 配置）；dev 环境取 `.env.development`。
- 路由需声明 `meta.title` 才会显示动态标题；未声明的路由统一回退为纯站点名。
- 关闭开关时不显示页面名，标题固定为站点名。
- `showDynamicTitle` 与主题、水印等同属 `SystemSetting`，经设置页「保存设置」落盘。
