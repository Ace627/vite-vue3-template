# 动态标题（Dynamic Document Title）

## 功能定位

路由切换时按当前页面改写浏览器标签页标题（格式 `页面名 - 站点名`），开关和持久化都放在 SettingPanel 抽屉里。

## 实现要点

| 文件 | 职责 |
|---|---|
| `src/hooks/useDynamicTitle.ts` | 核心：watch 路由 `path` 与 `showDynamicTitle`，据此写 `document.title` |
| `src/App.vue` | 根组件调用 `useDynamicTitle()` 启用（应用级单例） |
| `src/store/modules/setting.ts` | 暴露响应式 `showDynamicTitle` 状态 |
| `src/defaultSettings.ts` | 默认 `showDynamicTitle: true`（默认开启） |
| `src/layout/components/SettingPanel/index.vue` | 开关 UI：`<el-switch v-model="settingStore.showDynamicTitle" />` |
| `src/router/modules/static.route.ts` | 路由 `meta.title` 提供各页面名称 |

机制：`useDynamicTitle()` 内 `watch([route.path, showDynamicTitle], ..., { immediate: true })`。开启且路由声明了 `meta.title` 时标题为 `页面名 - 站点名`；否则（关闭或未声明）回退为纯站点名（取自 `VITE_APP_TITLE`）。

## 这么做的好处

- **多个标签页好认**：开了一堆标签或窗口时，一眼能看出当前在哪个页面。
- **可关可存**：在 SettingPanel 里即时开关，走 store 落盘，不强制你开。
- **声明式**：页面标题写在路由 `meta`，不用在各个组件里零散维护。
- **很轻**：只动 `document.title`，不挂额外 DOM，不引新依赖。

## 对工程化的好处

- **逻辑集中**：标题逻辑全在一个 hook 里，页面只在路由 `meta` 声明名字。
- **配置归一**：`showDynamicTitle` 归到 `SystemSetting`，和主题、水印、尺寸同一个 store 管，复用同一套保存 / 重置流程。
- **加页面零成本**：新页面只要在路由 `meta` 加个 `title`，hook 和 UI 都不用动。
- **不另造轮子**：开关组件和 `saveSetting` 持久化都是现成的，直接复用。

## 注意事项

- 站点名取自 `VITE_APP_TITLE`（`.env` 配置）；dev 环境取 `.env.development`。
- 路由得声明 `meta.title` 才显示动态标题；没声明的统一回退成纯站点名。
- 关掉开关就不显示页面名，标题固定为站点名。
- `showDynamicTitle` 和主题、水印一样属于 `SystemSetting`，经 SettingPanel「保存配置」落盘。
