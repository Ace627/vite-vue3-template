# 主题切换

## 功能定位

运行时在亮 / 暗主题间切换：命令式同步 `<html>.dark` 类驱动全站 CSS 变量明暗，并叠加 View Transitions API 圆形扩散动效；不支持该 API 的浏览器自动降级为直接切换。导航栏 `ThemeSwitch` 委托同一逻辑层，无重复实现。

> 与 `../UI组件/ElementPlus自定义主题.md` 区分：那篇是**编译期** SCSS 变量覆盖 + 暗黑 css-vars 注入（换肤的皮肤）；本篇是**运行时**切类 + 动效（切换的动作）。两者互补。

## 实现要点

| 落地点 | 职责 |
| --- | --- |
| `src/hooks/useTheme.ts` | `useTheme()` 返回 `isDark` / `applyTheme` / `toggleTheme`；负责切 `<html>.dark` 类、圆形扩散动效、防 FOUC、降级 |
| `src/layout/index.vue` | `const { isDark } = useTheme()` 取暗色态，驱动水印字体明暗 |
| `src/layout/components/Navbar/ThemeSwitch.vue` | `toggleTheme` 用点击坐标做从点击点扩散的圆形动效，复用 `applyTheme` |
| `src/store/modules/setting.ts` | `theme` 状态 + `saveSetting` 持久化（见 `../构建与工程化/全局设置中心.md`） |

## 机制

- `applyTheme(theme, event?)`：`run()` 内先更新 `settingStore.theme` 与 `<html>.dark` 类，再 `saveSetting({ showTip: false })` 持久化。
- 圆形扩散：有 `event` 坐标从点击点扩散、无坐标从屏幕中心；半径取覆盖全屏的 `hypot`；暗色用 `::view-transition-old(root)`、亮色用 `::view-transition-new(root)`，缓动 `cubic-bezier(0.28, 0, 0.44, 1)`。
- 降级：`typeof document.startViewTransition !== 'function'` 时直接 `run()`，无动画但功能不损。
- 防 FOUC：首次进入若 `isDark` 为真，幂等地给 `<html>` 加 `dark` 类，避免闪烁。

## 好处

- **圆形扩散动效**：主题切换有空间连贯的视觉反馈，体验优于硬切。
- **渐进增强**：不支持 View Transitions 的浏览器自动降级，功能零损失。
- **明暗联动**：`isDark` 被 layout 水印等统一消费，一处切换全站跟随。
- **持久化**：刷新后保持上次主题。

## 工程化好处

- **统一逻辑层**：导航栏 `ThemeSwitch` 委托 `useTheme`，无重复切换代码。
- **与编译期主题解耦**：运行时切类即可驱动 Element Plus 暗黑 css-vars，两套机制各管各的。
- **关注点分离**：动效细节封装在 hook，组件只调 `applyTheme(theme, event)`。
- **可复制**：View Transitions 圆形扩散是社区标准范式，可直接复用。

## 注意事项

- `saveSetting` 必须在 `startViewTransition` 的 `run` 回调内、且 `theme` 已更新之后调用，否则保存旧主题。
- 降级浏览器无动画，但直接完成切换。
- `isDark` 由 `settingStore.theme === 'dark'` 派生，不要在组件里再写一份明暗判断。
- 防 FOUC 的 `dark` 类加在 `useTheme()` 首次执行时，早于任何渲染依赖。
